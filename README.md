# BIS 375 Web Development Workshop

This repository contains a guided notebook for beginner web development students who are using **GitHub Codespaces** and **GitHub Copilot Chat** to build a simple website.

## What students will learn

By following the notebook, students will:
- choose an academic-appropriate website topic
- build page structure with HTML
- style the page with CSS
- add a small interactive feature with JavaScript
- preview and test the site in the browser inside Codespaces

## How to use this repository

1. Open this repository in **GitHub Codespaces**.
2. Open `notebooks/build_your_first_website.ipynb`.
3. Run the notebook cells from top to bottom.
4. Copy the provided prompts into **GitHub Copilot Chat** in **Agent** mode.
5. Accept Copilot's changes to the files in the `website/` folder.
6. Use the notebook's preview-server and validation cells to test your work.

## What the notebook does

The notebook is designed to be beginner-friendly and sequential. It includes:
- setup steps for a `website/` working folder
- copy/paste prompts for HTML, CSS, and JavaScript tasks
- instructions for previewing the site in the browser
- a simple validation cell to confirm that the HTML, CSS, and JavaScript are all connected
- a browser testing checklist and a recovery prompt if something breaks

## Suggested website topics

Choose a topic that is appropriate for an academic setting, such as:
- campus study group
- tutoring center page
- library event page
- student club landing page
- healthy study habits resource page

If students do not want to choose a topic themselves, the notebook includes a prompt that asks Copilot to choose one.
